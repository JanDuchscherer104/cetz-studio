# Render, compare, decide

Freeze the accepted baseline and scientific inputs before making an alternative.
Keep style-only and semantic changes separate. Render baseline and candidate
with the same destination width and relevant scales/camera; label deliberate
exceptions. A screenshot from another source revision is not a fresh baseline.

Inspect semantic errors first, then reading order, alignment, whitespace,
connection routing, label placement, clipping and final-size legibility.
For 3D, inspect hidden/visible relationships, projection and registered overlays.
Use grayscale where color carries meaning. A larger or more elaborate figure
must explain a distinct relationship rather than repeat the surrounding prose.

Record one concrete next change after each comparison. A rejected iteration
leaves the accepted baseline intact. Delegation does not remove the integrating
agent's responsibility to inspect the final artifact. Mark author/self-review,
independent review and unavailable inspection accurately.

Keep stable identity and lineage with the consumer's existing catalog when one
exists. Minor revisions do not require new registry entries. A supplied favorite
can be recorded without redesign; selection neither edits a manuscript include
nor approves a scientific claim. Only the manuscript owner controls inclusion,
caption and the final page. Check evaluated inclusion where the project provides
that capability; source-text search alone may not establish it.

Return the source/render/input identities, actual inspections, retained lesson,
selection state and outstanding evidence. No rendering tool means a candidate
source and an explicit render gap, not an invented successful preview.
